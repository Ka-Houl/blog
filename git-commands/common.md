# 常用命令速查

| 场景 | 命令 |
| --- | --- |
| 初始化仓库 | `git init` |
| 克隆仓库 | `git clone <url>` |
| 查看状态 | `git status` |
| 提交改动 | `git add . && git commit -m "msg"` |
| 推送到远端 | `git push origin main` |
| 拉取更新 | `git pull` |
| 创建分支 | `git checkout -b feat/xxx` |
| 查看历史 | `git log --oneline --graph` |

> 持续补充你实际用到的命令与踩坑案例。
